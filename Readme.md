# E-Commerce Platform
   A full-stack e-commerce web application built with the MERN stack, featuring secure authentication, payment integration, and an admin dashboard.
##  Live Demo
https://e-commerce-admin-payment.onrender.com/


## Features
 **User Authentication** — JWT-based login/signup with access & refresh tokens
 **Product Management** — Browse products by category
 **Shopping Cart** — Add, remove, and update quantities
 **Coupon System** — Apply discount coupons at checkout
 **Payment Integration** — Stripe payment gateway
 **Order Management** — Order creation and tracking
 **Admin Dashboard** — Manage products, view analytics
 **Security** — Redis-based token storage, HTTP-only cookies


##  Tech Stack
**Frontend:**
- React.js
- Tailwind CSS
- Zustand (State Management)
- Axios
- Framer Motion (Animation)

- 
**Backend:**
- Node.js
